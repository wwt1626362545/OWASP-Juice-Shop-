# OWASP Juice Shop 测试报告

**被测项目：** OWASP Juice Shop  
**源码版本：** GitHub `v20.3.0`  
**运行环境：** 官方 Windows/Node 26 打包版，本地 `http://localhost:3000`  
**测试日期：** 2026-10-31  
**执行人：** Codex  
**报告结论：** 主业务链路通过；发现 2 个非阻断接口语义问题

---

## 1. 执行摘要

本轮在本地固定版本环境完成业务流程、接口、UI、性能、并发、钱包余额和取消订单能力验证。

最终 Playwright 套件：

- **8/8 测试通过**
- **0 失败**
- **0 跳过**
- **0 Flaky**
- 总耗时 **18.9 秒**

核心业务闭环通过：注册 → 登录 → 搜索 → 加购 → 修改数量 → 结算 → 订单历史。

测试过程中发现两个非阻断问题：

1. 同一购物车 5 个并发加购请求中，1 个返回 200，4 个返回 500。数据保持一致，但冲突响应应使用明确的 4xx。
2. 钱包余额不足时，订单被正确拒绝且购物车保留，但接口返回 500，而不是明确的 4xx 业务错误。

订单取消能力在当前版本中不存在，标记为 Not Applicable。

- 并发数：5。
- 成功：5/5。
- 总耗时：67.87 ms。
- 所有响应均返回至少 3 条 Apple 商品。

### 4.3 并发加购

- 并发数：5。
- 同一用户、同一购物车、同一商品。
- HTTP 状态：`200, 500, 500, 500, 500`。
- 最终数据：1 条商品记录，数量为 1，无重复数据。
- 结论：数据一致性通过，但 4 个并发冲突请求返回 500，接口语义不合格。

## 5. 取消订单与钱包余额

### 5.1 取消订单

源码检查范围：

- `routes/order.ts`
- `routes/orderHistory.ts`

结果：

- 没有取消订单接口。
- 订单历史页面没有取消订单按钮。
- 状态：**Not Applicable / 产品能力不存在**。

### 5.2 钱包余额不足

- 新用户钱包余额为 0。
- 购物车中放入 Apple Juice。
- 使用 `paymentId=wallet` 结算。
- 结果：订单被拒绝，购物车保留，订单历史无新增记录。
- 接口状态：500。
- 结论：业务保护正确，但应将余额不足映射为 402/409/422 等明确 4xx。

## 8. 残留风险

1. 当前高级场景为小规模基线，不等同于高并发压测。
2. 未验证订单取消、退款、库存扣减和支付成功余额扣减。
3. 本轮只验证基础负向认证，不覆盖安全漏洞。
4. 本地打包版使用内存数据库，服务重启后测试数据会重置。
5. 未执行跨用户购物车访问隔离。

---

## 9. 结论

在本报告范围内，OWASP Juice Shop 20.3.0 的电商主流程、顺序性能、搜索并发、订单创建和钱包余额拦截均可正常运行，数据未发现损坏。

建议修复两个接口语义问题后再扩展高并发、订单取消与支付余额扣减测试。
