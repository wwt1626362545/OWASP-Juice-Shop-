# OWASP Juice Shop 业务流程测试计划

**项目：** OWASP Juice Shop  
**版本：** 20.3.0  
**测试目标：** 本地官方打包版 `http://localhost:3000`  
**测试日期：** 2026-10-31  
**文档状态：** Final

---

## 1. 项目选择

本轮选择 GitHub 开源项目 [OWASP Juice Shop](https://github.com/juice-shop/juice-shop/tree/v20.3.0) 作为被测对象。

选择依据：

1. 项目是 OWASP Flagship 项目，GitHub 约 1.43 万 Stars，维护活跃。
2. 应用包含完整的电商业务闭环：注册、登录、商品搜索、购物车、数量修改、结算、订单历史。
3. 同时提供 UI 和 REST API，适合功能、接口、端到端和自动化测试。
4. 项目本身就是用于测试、培训和安全演练的应用，测试数据可安全模拟。

本机没有 Docker。公开 Demo 在测试期间受到限流并返回 503，因此下载官方 Windows/Node 26 打包版并本地运行。本地 `/rest/admin/application-version` 确认版本为 `20.3.0`。

## 2. 测试目标

- 验证用户从注册到订单查询的核心业务链路。
- 验证商品目录、搜索、认证和购物车接口的契约与业务断言。
- 验证 UI 登录、搜索、加入购物车和购物车展示。
- 生成可重复执行的 Playwright 自动化测试和报告。
- 识别影响业务流程的缺陷、环境风险与未覆盖范围。

## 3. 测试范围

### 3.1 范围内

- 用户注册。
- 正确密码和错误密码登录。
- 商品目录查询。
- 商品关键词搜索。
- 商品加入购物车。
- 修改购物车商品数量。
- 购物车详情查询。
- 订单结算。
- 订单历史查询。
- 搜索结果和购物车价格展示。
- API 响应状态、关键字段、业务数据和订单闭环断言。
- 商品搜索接口的顺序性能基线。
- 5 并发商品搜索。
- 同一用户、同一购物车的 5 并发加购。
- 订单取消能力检查。
- 钱包余额不足结算。

### 3.2 范围外

- 漏洞利用、渗透测试和挑战解题。
- 支付渠道真实扣款。
- 管理后台、文件上传、聊天机器人和 Web3 功能。
- 多语言、多浏览器兼容性的完整矩阵。
- 大规模性能容量测试和高并发压力测试。
- 代码覆盖率和白盒测试。

## 4. 测试策略

采用基于风险的测试策略，优先验证影响下单闭环的路径。

| 层级 | 重点 | 方法 |
|---|---|---|
| API | 状态码、响应结构、认证、购物车和订单 | Playwright APIRequestContext |
| UI | 登录、搜索、加购、购物车价格 | Edge 无头浏览器 |
| End-to-End | 注册到订单历史的完整链路 | API 业务流程串联 |
| Negative | 错误密码、未覆盖的权限边界 | 正向/负向断言 |
| Regression | 商品和订单主链路 | 每次执行完整套件 |
| Performance | 顺序搜索延迟和成功率 | 3 次预热 + 20 次测量 |
| Concurrency | 搜索与同一购物车加购 | 5 个同步请求 |
| Payment | 钱包余额不足 | 结算拦截和订单不变断言 |

### 4.1 优先级

- **P0：** 注册、登录、搜索、加购、结算、订单查询。
- **P1：** 错误密码、数量修改、价格一致性、权限隔离。
- **P2：** 退出登录、空搜索结果、空购物车限制。

### 4.2 测试设计方法

- 场景法：覆盖用户主业务流程。
- 等价类：正确/错误认证、有效/无效关键词。
- 边界与异常：空购物车、跨用户资源、错误密码。
- 契约断言：状态码、字段类型、金额、订单号格式。
- 端到端追踪：检查订单历史是否包含本次生成的订单号。
- 性能统计：记录 min、avg、P50、P90、P95 和 max。
- 并发一致性：比较请求成功数和实际持久化数量。

## 7. 进入与退出标准

### 7.1 进入标准

- 本地服务首页可访问。
- `/rest/admin/application-version` 返回 20.3.0。
- 商品接口和搜索接口可访问。
- Playwright 和 Edge 可正常启动。
- 测试账号注册接口可用。

### 7.2 退出标准

- P0 自动化用例全部通过。
- 完整注册到订单历史链路通过。
- 无阻断业务主流程的产品缺陷。
- 报告、日志、截图和测试用例可追溯。
- 未覆盖范围与残余风险已记录。

## 8. 风险与应对

| 风险 | 概率 | 影响 | 应对 |
|---|---|---|---|
| 本地进程异常退出 | 低 | 中 | 保存 stdout/stderr；启动前检查端口 |
| 数据在服务重启后重置 | 中 | 低 | 使用内存数据库可接受 |
| 并发测试影响业务数据 | 中 | 中 | 使用专用账号并在用例前清空购物车 |
| 钱包成功支付未验证 | 高 | 中 | 作为明确未覆盖项记录 |
| 安全漏洞行为影响普通业务断言 | 中 | 中 | 本轮只验证正常业务和基础负向认证 |
| 浏览器下载受限 | 中 | 低 | 使用系统 Edge channel |
